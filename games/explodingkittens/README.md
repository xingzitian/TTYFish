# 爆炸猫（Exploding Kittens）

TTYFish 的第二款游戏，使用当前 Original Edition 基础规则（2–5 人）。
规则引擎不依赖网络或时钟；SDK 适配器、协议和 TUI 分别位于模块根目录、
`protocol` 和 `ui`。规则参考：[官方规则页](https://www.explodingkittens.com/pages/rules-kittens)。

从 TUI 大厅选择 **爆炸猫**，创建或加入房间。
等候房间沿用 UNO 的视觉结构：常驻房间码、人数/上限及玩家名单，
标明自己、房主、电脑和掉线状态；未开局不显示牌堆或手牌。

## 界面

```
[TURN] 电脑3(7)  >>>  *你*(7)  >>>  电脑1(7)  | 需摸:1 存活:4/4
[DECK] 牌堆: 14张 [Bomb x2|14.3%]  弃牌顶: [功能|洗牌](电脑2)
[HAND] 1.[保命|拆弹] 2.[功能|否决] 3.[功能|攻击] 4.[功能|预言] → 1/2
[MSG]  轮到你：按数字出功能牌，或按 D 摸牌
[CMD]  [?]帮助 [1-5]出牌 [G]对子盲抽(0) [D]摸牌 [T]聊天 [Tab]玩家 [-=]翻页
```

- **TURN**：与 UNO 一样逐字符滑动，座次只向前推进（这个游戏没有反转）。
  当前玩家居中，淘汰者跳过；`需摸:N` 是当前玩家还需完成的回合数，
  `存活` 是活着的/总人数。
- **DECK**：牌堆张数、**还剩几颗炸弹与下一张摸到炸的概率**、弃牌堆顶和是谁打的。
- **HAND**：`[类别|名字]`——`保命` / `功能` / `猫牌` / `炸弹` 四类。
  黑白终端下靠文字也能分辨，颜色只是辅助。
- **MSG**：永远只说当前这一件事；限时效果在这里显示**真实倒计时**。
- **CMD**：永远只列"这个阶段真的能按"的键。
  窄屏按完整操作项折行，不隐藏仍可用的键或手牌。

## 操作

| 按键 | 用途 |
| --- | --- |
| `1-5` | 出当前页功能牌（攻击 / 跳过 / 洗牌 / 预言 / 索要） |
| `G` | **对子盲抽**：自动找出两张同款猫牌，括号里是可用次数 |
| `D` | 摸牌并结束一次回合 |
| `N` | **否决**：别人出牌时一键打出，括号里是你的否决牌数 |
| `P` | 放弃响应；查看自己预言结果时结束展示 |
| `T` | 打开快捷语选择器，再按数字发送；等待别人时也可用 |
| `Enter` | 确认指定埋雷位置 |
| `Esc` | 取消当前选择；没有选择时按平台流程退房 |
| `-` / `=` | 手牌翻页；埋雷「指定位置」时用来调数值 |
| `Tab` | UNO 样式玩家列表（不替换 TURN）；再按 Tab / Esc 关闭，5 秒自动收回 |
| `?` / `/` | 键位一览（按当前阶段只列可用键） |
| `I` / `M` | 切换极简/丰富、颜色深浅；埋雷时 `I` 优先进入指定位置 |
| `S` / `B` / `V` | 大厅里：开始、加电脑、投票重开 |
| `Q` / `Ctrl+B` | 断开连接 / 老板键 |

## 几个特殊场面

**对子盲抽**（按 `G`）：屏幕下方变成目标选择器，按数字立即选人，
`Esc` 取消。只列有手牌的存活对手，每页两人，`-=` 翻页；索要使用同样的选择器。

```
[MSG] 请选择你要盲抽的目标玩家：
>> 选择目标: [1]电脑A(4)  [2]电脑B(3)  [Esc]取消
```

**否决窗口**：别人出牌后有 5 秒，MSG 显示 `生效倒计时: 3.6s`，按 `N` 打否决、
`P` 放弃。
否决后明确显示「已被否决」或「原效果将恢复」，窗口结束后记录最终结果。
按住或连按 `N` 不会连续消耗手牌来否决自己的否决；对手反否决后可再次响应。
只要窗口还未结束，即使先前放弃，也仍能用否决牌响应。

**预言**：打出后先过否决窗口，然后**只有你能看到**牌堆顶（10 秒倒计时），
其他人只看到「某某正在偷看牌堆顶...」。炸弹用下划线强调。
这只是展示倒计时，不会额外暂停规则或延长回合；打牌、摸牌或换人后立即清除，
被否决的预言不会开启展示。

**摸到炸弹**：你只需要决定塞回哪里，确认放回时自动消耗拆弹牌。
旁观者只看到等待拆弹，不会看到或获得埋雷操作。

```
>> 埋雷位置: [0]牌堆顶 [1]第2张 [2]第3张 [B]牌堆底 [R]随机 [I]指定位置(0-13)
```

## 颜色

| 牌 | 面 |
| --- | --- |
| 保命牌 | `[保命|拆弹]`（绿） |
| 功能牌 | `[功能|否决/攻击/跳过/索要/洗牌/预言]`（统一橘色） |
| 猫牌 | `[猫牌|卷饼/西瓜/土豆/胡子/彩虹]`（每类一色，**两份同款相邻**） |
| 炸弹 | `[炸弹|爆炸猫]`（红） |

手牌按「保命 → 功能 → 猫牌」排序，同种聚在一起，凑对子一眼可见。

## 规则要点

功能牌及组合进入共享 **5 秒**否决窗口，所有存活玩家放弃可提前结算。
每张否决牌重开窗口，奇数次取消、偶数次恢复效果。
超时等同于其余玩家放弃，不会自动消耗他们的否决牌。
交牌和拆弹使用平台现有回合超时与掉线托管机制。
机器人仅使用自己的观察视图，策略为保底版本，不会主动使用否决。
牌堆顺序、其他人的手牌、预言结果和拆弹放回位置不会发送给无权查看的人；
`[Bomb xN]` 只是**数量**（公开信息），不含顺序。

当前不提供 PT 奖励、扩展牌或网页牌桌，也没有三张同款组合。
