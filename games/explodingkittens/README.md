# 爆炸猫（Exploding Kittens）

TTYFish 的第二款游戏，使用当前 Original Edition 基础规则（2–5 人）。
规则引擎不依赖网络或时钟；SDK 适配器、协议和 TUI 分别位于模块根目录、
`protocol` 和 `ui`。规则参考：[官方规则页](https://www.explodingkittens.com/pages/rules-kittens)。

从 TUI 大厅选择 **爆炸猫**，创建或加入房间。

## 操作方式

**全部是单键操作**，和 UNO 一致：没有输入框、没有命令语法。屏幕上的
`[CMD]` 行永远写着"现在能按什么"。

| 按键 | 用途 |
| --- | --- |
| `1-9` | 出/选对应编号的手牌（编号就是屏幕上牌前面的数字） |
| `D` | 摸牌并结束一次回合 |
| `Enter` | 确认（组合、目标、拆弹位置） |
| `Esc` | 取消当前选择；没有选择时按平台流程退房 |
| `-` / `=` | 手牌翻页（拆弹时用来调放回位置） |
| `Tab` | 列出所有玩家 |
| `?` / `/` | 键位一览（按当前阶段只列可用键） |
| `I` / `M` | 切换极简/丰富、颜色深浅 |
| `S` / `B` / `V` | 大厅里：开始、加电脑、投票重开 |
| `Q` / `Ctrl+B` | 断开连接 / 老板键 |

## 几种牌的出法

- **攻击 / 跳过 / 洗牌 / 预知未来**：按数字，**立刻生效**。
- **索要**：按数字选牌 → 屏幕列出可选目标 → 按数字选人 → `Enter` 确认。
- **猫牌（凑对子/三张）**：按第一张进入候选（牌前出现 `▸`），再按**同色**的猫牌
  继续累加；按错颜色立即取消。凑够后 `Enter` 进入选目标。
  三张组合在选完目标后再按数字选"要哪种牌"。
- **反制**：出现反制窗口时，按数字打出紫色的反制牌；`P` 放弃。
- **交牌**：被人索要时，按数字把那张交出去。
- **拆弹**（两步）：按数字先选一张绿色的拆弹牌 → 屏幕切换成"放回第几张"，
  用 `-`/`=` 调整位置（`0` = 牌顶），`Enter` 确认。

手牌按牌种自动排序，**五只猫牌永远挨在一起**，按相邻数字就是一对。

## 颜色即身份

五只猫牌在规则上完全等价，所以用颜色区分，名字取本地化叫法：

| 牌面 | 名字 | 颜色 |
| --- | --- | --- |
| `[橙\|橘]` | 橘猫 | 橙 |
| `[花\|花]` | 三花猫 | 品红 |
| `[白\|奶]` | 奶牛猫 | 白 |
| `[金\|金]` | 金渐层 | 黄 |
| `[蓝\|蓝]` | 蓝猫 | 蓝 |

其余牌：`[红|爆]` 爆炸猫、`[绿|拆]` 拆弹、`[紫|否]` 反制、`[橙|攻]` 攻击、
`[黄|跳]` 跳过、`[青|要]` 索要、`[蓝|洗]` 洗牌、`[蓝|预]` 预知未来。
（无色模式下牌面退化成纯文本 `[橙|橘]`。）

## 规则要点

功能牌及组合进入共享 **5 秒**反制窗口，界面上有**真实倒计时**；
所有存活玩家放弃可提前结算。每张反制牌重开窗口，奇数次取消、偶数次恢复效果。
超时等同于其余玩家放弃，不会自动消耗他们的反制牌。
交牌和拆弹使用平台现有回合超时与掉线托管机制。
机器人仅使用自己的观察视图，策略为保底版本，不会主动使用反制。
牌堆顺序、其他人的手牌、预知结果和拆弹放回位置不会发送给无权查看的人。

当前不提供 PT 奖励、扩展牌或网页牌桌。
